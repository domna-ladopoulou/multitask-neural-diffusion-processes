# Multi-Task NDP

Note that this fodler contains code for the MT-NDP architecture.

The original NDP architecture (contained in neural-diffusion-processes/) was originally developed in https://arxiv.org/abs/2206.03992 and the code was also provided at https://github.com/vdutor/neural-diffusion-processes

I copied the Git repo from https://github.com/vdutor/neural-diffusion-processes and have made changes to the architecture to develop the MT-NDP. Notably, this includes the addition of the Encoder.
